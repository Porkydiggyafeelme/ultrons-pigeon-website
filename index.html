Windows first · macOS underway

The direction

Everyday email, with room to think.

The aim is a focused desktop home for reading, composing and keeping up with the mail that matters—without presenting unfinished ideas as ready-to-use features.

One familiar workspace

Traditional inbox, folders, search, reading and compose flows are part of the intended direction. Provider support and sync are still being validated.

Windows first, macOS in development

The Windows desktop prototype is under active development. Work toward a macOS version has also begun, including shared-code readiness; the Mac-native interface and secure storage still need implementation and testing.

Optional security assistance

Explainable, optional security review is a future direction. Live AI analysis is not available, and the app currently sends no mailbox content to an AI service.

Development status

Early, private beta work.

Neither Windows nor macOS has a public release or availability date. The macOS edition is at an earlier development stage; provider integrations and platform-specific security must be qualified before release.

What the source shows: Microsoft browser sign-in, incremental sync and an encrypted local mail-cache path are implemented but need application registration and live-account validation. Gmail backend work is incomplete for live authorization; Yahoo/AOL and live AI analysis are not operational. No public download is available on either platform. Shared application components are being evaluated for macOS; a Mac-native UI, Mac Keychain integration, macOS execution tests and packaging are not yet complete. Planned provider coverage includes Gmail, Yahoo/AOL, Outlook/Hotmail and other providers, subject to provider authorization and successful qualification; that is a roadmap, not current availability.
